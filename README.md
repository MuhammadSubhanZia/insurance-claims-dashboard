# 🚗 Insurance Claims Recovery Analytics Dashboard

An interactive business intelligence dashboard built using **Python**, **Streamlit**, and **Plotly** for analyzing insurance claim recovery data. The project transforms raw insurance claim records into meaningful insights through data preprocessing, exploratory data analysis, and interactive dashboards.

---

## 📌 Project Overview

Insurance companies handle thousands of claims every year, making it difficult to monitor recoveries, collections, officer performance, and geographical trends manually.

This dashboard provides executives and analysts with a centralized platform to:

- Monitor recovery performance
- Track claim status
- Analyze officer productivity
- Identify high-risk locations
- Study recovery reasons
- Evaluate data quality
- Explore trends over time
